Research questions

A stock can link several House disclosure filers when each reports buying it. Looking at these ties as a network lets me ask which stocks link the most filers, how broadly shared buying connects filers, and how much that overlap depends on the most widely shared stock.

Network data

Course connection Chapter 2 · What is a Network? and Chapter 13 · Two Mode Networks explain how to define nodes and ties and represent two kinds of nodes in one graph.

I used the frozen 2025 extract from my presentation project. The source is U.S. House Periodic Transaction Reports (PTRs). I kept accepted ticker matches classified as public-stock purchases with transaction dates in 2025. Filer identities use cleaned display names, and ticker symbols are standardized to uppercase. Each unique filer–ticker pair counts once, even if the filer reported multiple purchases. A disclosure may cover a spouse’s or dependent’s purchase.

raw <- read.csv('sna-input.csv', fileEncoding = 'UTF-8-BOM')
rows <- subset(raw, transaction_type == 'P' & asset_type == 'ST' &
  ticker_parse_status == 'accepted' & grepl('^2025-', transaction_date))
rows$filer <- trimws(sub('^(Honorable|Hon\\.?) +', '', rows$politician,
                        ignore.case = TRUE))
rows$ticker <- toupper(trimws(rows$ticker_v8_2_cleaned))
rows <- subset(rows, !is.na(ticker) & nzchar(ticker) & nzchar(filer))
ties <- unique(rows[c('filer', 'ticker')])
all_degree <- table(ties$ticker)
shared <- subset(ties, ticker %in% names(all_degree[all_degree >= 2]))
incidence <- xtabs(~ filer + ticker, shared)
stopifnot(nrow(rows) == 3179, nrow(incidence) == 45,
          ncol(incidence) == 355, sum(incidence) == 1291)
print(c(purchase_records = nrow(rows), all_filers = length(unique(ties$filer)),
        all_tickers = length(all_degree), shared_graph_filers = nrow(incidence),
        shared_graph_tickers = ncol(incidence), shared_graph_ties = sum(incidence)))

The two-mode graph links filers to tickers. It keeps tickers bought by at least two distinct filers. The full extract contains 55 filers and 855 tickers. The shared-stock graph includes 45 filers, 355 tickers, and 1,291 ties. The other 10 filers only reported qualifying purchases of tickers that no other filer in the extract bought.

Which stocks connect the most filers?

Course connection Chapter 6 · Centrality explains degree as the number of neighbors. Here, a stock’s neighbors are the filers who reported buying it.

Stock degree is the number of distinct filers linked to a ticker. The bars show the five highest-degree tickers, with alphabetical ordering for ties.

stock_degree <- colSums(incidence)
top <- head(stock_degree[order(-stock_degree, names(stock_degree))], 5)
print(top)
par(mar = c(4, 5, 1, 2))
y <- barplot(rev(top), horiz = TRUE, las = 1, xlim = c(0, 22),
             xlab = 'Distinct House disclosure filers', col = '#166675',
             border = NA, cex.names = 0.95)
text(rev(top) + 0.5, y, rev(top), pos = 4, cex = 0.85)
AMZN AAPL AVGO MSFT NVDA 
  19   15   15   14   14

Amazon (AMZN) links 19 of the 45 filers in the shared-stock graph. Apple (AAPL) and Broadcom (AVGO) each link 15. These counts measure how widely a ticker was shared across filers. They give the same weight to a filer who reported one purchase and a filer who reported several.

How much do filers overlap?

Course connection Chapter 13 · Two Mode Networks explains the projection from filer–stock ties to filer–filer ties. Chapter 5 · Connectivity explains why belonging to one component means every filer can reach every other through some path.

I projected the two-mode graph onto filers. Two filers have an undirected edge when they share at least one ticker. The matrix product counts shared tickers per pair. Density uses the upper triangle to count each pair once, and the diagonal is excluded. For the sensitivity check I removed AMZN and held the same 45 filers fixed so the denominator stayed comparable.

overlap <- tcrossprod(as.matrix(incidence))
pair_weights <- overlap[upper.tri(overlap)]
without_amzn <- tcrossprod(as.matrix(incidence[, colnames(incidence) != 'AMZN']))
without_weights <- without_amzn[upper.tri(without_amzn)]
edges <- sum(pair_weights > 0)
remaining <- sum(without_weights > 0)
possible <- length(pair_weights)
stopifnot(edges == 494, possible == choose(45, 2))
reached <- 1L
repeat {
  next_reached <- which(colSums(overlap[reached, , drop = FALSE] > 0) > 0)
  if (identical(next_reached, reached)) break
  reached <- next_reached
}
stopifnot(length(reached) == 45)
print(data.frame(graph = c('All shared stocks', 'Without AMZN'),
                 edges = c(edges, remaining), possible_pairs = possible,
                 density_pct = round(100 * c(edges, remaining) / possible, 1)),
      row.names = FALSE)
print(c(connected_component_size = length(reached),
        pairs_lost_without_amzn = edges - remaining))
par(mar = c(4, 5, 1, 2))
pair_counts <- rbind('Share a ticker' = c(edges, remaining),
                     'No shared ticker' = possible - c(edges, remaining))
barplot(pair_counts, names.arg = c('All shared stocks', 'Without AMZN'),
        col = c('#166675', '#d7e1e5'), border = NA,
        ylim = c(0, 1250), ylab = 'Filer pairs')
legend('top', legend = rownames(pair_counts), fill = c('#166675', '#d7e1e5'),
       horiz = TRUE, bty = 'n')

 All shared stocks   494            990        49.9
      Without AMZN   457            990        46.2

                      45                       37

The full projection has 494 of 990 possible edges (49.9%). All 45 filers are reachable within one connected component. The sensitivity check counts only pairs whose sole shared ticker was Amazon. Pairs that also shared another stock stay connected. This distinguishes Amazon’s high stock degree from its effect on the number of filer pairs with any overlap.

Without Amazon, 457 pairs remain connected (46.2% density). The projection loses 37 edges.

Interpretation and limits

The density depends on the population and time window. It describes the 45 filers with a shared stock purchase during the year. Including the 10 filers with no shared purchases leaves the same 494 edges across 1,485 possible pairs, for 33.3% density. Annual overlap can connect two filers whose purchases occurred months apart. Widespread market interest in a stock offers one possible explanation for overlap. These data provide no test of coordination, access to privileged information, or investment performance.

The extract excludes sales, other asset types, and unresolved tickers. It can also miss records or contain incorrect ticker and name matches. The presentation’s committee views provide context about institutional roles. The calculations here use purchase ties only, so committee membership does not create an edge or enter the sensitivity analysis.

Executive summary

  • Which stock links the most filers? Amazon connects 19 filers, followed by Apple and Broadcom at 15 each.
  • How common is shared buying? In the shared-stock graph, 494 of 990 filer pairs share at least one ticker, and all 45 filers belong to the same connected component.
  • How much does the network depend on Amazon? Removing AMZN leaves 457 of 494 edges. Only 37 pairs depend on Amazon alone for their connection.
